# Samsung Gauss Generative AI Models

Unveiled at the Samsung AI Forum in November 2023, Samsung Gauss is the proprietary generative artificial intelligence suite developed by Samsung Research.

## The Three Core Sub-Models
1. **Samsung Gauss Language**: A foundational large language model (LLM) designed to understand and generate natural human language. It facilitates tasks such as drafting emails, summarizing research reports, translating languages bidirectionally, and powering conversational assistant interfaces across consumer electronics and smart office environments.
2. **Samsung Gauss Code**: A specialized code generation and software development assistant operating in conjunction with a code assistant named 'code.i'. It assists software engineers in rapid code synthesis, automated test case generation, code refactoring, and code review documentation.
3. **Samsung Gauss Image**: A high-fidelity generative vision model capable of generating and modifying creative images. It performs image style transfers, resolution upscaling, and creative additions or inpainting to visual assets.

## On-Device AI Architecture and Privacy Protection
Samsung Gauss is optimized for hybrid deployment:
- **On-Device Execution**: Lightweight quantized variants execute locally on Samsung NPU hardware (such as Exynos 2400 and Snapdragon 8 Gen 3) ensuring zero transmission of sensitive personal data or audio transcripts to cloud servers.
- **Data Security**: On-device processing guarantees end-to-end data isolation, aligning with strict enterprise compliance standards.
